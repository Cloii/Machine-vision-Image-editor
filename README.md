# 🧠 Shape Detection Project
This project is a C++/CLI application that utilizes OpenCV for shape detection in images. The application provides a user interface for loading images, detecting shapes, and displaying the results. The project aims to demonstrate the integration of OpenCV with .NET and provide a simple, yet effective, shape detection tool.

## 🚀 Features
* Image loading and display
* Shape detection (circles, triangles, rectangles, squares)
* User interface for selecting images and viewing results
* Conversion between .NET Bitmap objects and OpenCV Mat objects
* Background worker for performing shape detection

## 🛠️ Tech Stack
* C++/CLI
* OpenCV
* .NET Framework
* Windows Forms
* OpenCvSharp4.Windows package
* NuGet package manager
